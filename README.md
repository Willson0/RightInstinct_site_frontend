## О проекте

**Верное чутьё** — это современный фронтенд-проект для маркетплейса собак, разработанный для подключения к готовому backend-решению.

Интерфейс обеспечивает удобную навигацию, просмотр каталога и взаимодействие с платформой через Telegram-авторизацию.  
Проект ориентирован на создание чистого, понятного и визуально привлекательного пользовательского опыта.

---

## Основной функционал

- Подключение к готовому backend
- Авторизация через Telegram
- Просмотр интерфейса маркетплейса
- Адаптивная верстка
- Современный и лаконичный UI
- Работа в связке с серверной частью проекта

## Установка

Стандартная установка проекта через npm.

```bash
npm install
```


---

## Запуск

```bash
npm run dev
```

После запуска проект будет доступен по адресу, указанному в терминале.
